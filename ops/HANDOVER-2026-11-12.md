## Rules that matter most in practice

- Push only when the owner says "push". Commit locally until then. Every push to `apps/` restarts the engine.
- Never change real-money settings (Live/Sim, stakes, limits) unless the owner says so.
- Never type or ask for the owner's passwords; he signs in to the admin, DigitalOcean and IPG.
- After a push, watch the deploy: the build id in `curl -sL <site>/members` (`"b":"..."`), then `/engine/health` until
  `telegram.connected` is true. Never start a second copy of anything on the Telegram session.
- Windows: Python edit scripts go in the scratch folder and run with `python -X utf8`; keep CRLF/BOM; never pipe a
  heredoc into python.
- Checks before a commit: `cd apps && npm run typecheck && npm test`; `cd apps/web && npx tsc --noEmit -p tsconfig.json && npx eslint . && npm test`.
